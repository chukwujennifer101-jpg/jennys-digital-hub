# Jenny's Digital Hub

A responsive storefront for laptops and computer accessories.

## Included

- Responsive homepage and product catalogue
- Product search and category filtering
- Shopping cart with quantity controls
- Checkout form that prepares an order message for WhatsApp
- Product enquiries for items whose prices need confirmation

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Important checkout notes

Orders are sent to WhatsApp for manual confirmation. This project does not currently process online payments, save orders to a database, manage inventory, or automatically confirm delivery. Bank transfer details should be provided directly to customers after the order and stock have been confirmed.
